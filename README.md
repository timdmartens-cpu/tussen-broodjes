# TUSSEN

De website van TUSSEN, een verzonnen broodjeszaak aan de Haarlemmerdijk in Amsterdam.
Gemaakt met de 10k-websites skill, naar het ontwerp van mendo.nl.

## Zelf bekijken

Dubbelklik `Start TUSSEN.command` in de map erboven, of start een server in deze map:

    python3 -m http.server 8791

Open daarna https://timdmartens-cpu.github.io/tussen-broodjes/#top in je browser.
Dubbelklikken op `index.html` werkt ook, maar dan zie je een stilstaand beeld in plaats van de scrollvideo.

## Wat staat waar

- `index.html` is de hele pagina.
- `assets/` bevat de stijl, de code, de video en de foto.

TUSSEN is een verzonnen merk. De beelden zijn met AI gemaakt.
